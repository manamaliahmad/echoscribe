EchoScribe

Free, unlimited audio → text. Open-source Whisper runs on your PC — no server, no account, no per-minute cost. Your audio never leaves this device.

Drop an audio file here or click to choose one
MP3, WAV, M4A, OGG, WebM, FLAC — any length
Choose an audio file to begin. First run downloads the model once (free, from Hugging Face) and caches it — after that it works offline.

Privacy: the Whisper model runs inside this browser tab on your CPU/GPU. Audio is decoded locally and never uploaded anywhere — the only download is the model itself, once, from Hugging Face. No account, no limits, no cost, ever.
If you see an error mentioning wasm or jsep, the engine file is missing: download ort-wasm-simd-threaded.jsep.wasm and place it in the extension's lib/ folder, then reload this page.
